# MD 羅盤

MD 羅盤是一款以 iPhone 方向感測器搭配傳統羅盤資訊的方位工具，提供簡易盤與多層三元盤，著重坐山、朝向、卦象及分金格界的清楚對照。

## 功能

- **簡易盤**：後天八卦、二十四山，區分地盤正針內圈與天盤縫針外圈，並列出各圈山位及交界。
- **複雜三元盤**：圓圖與方圖各六十四卦，分別顯示卦名、六爻卦象及上下卦。由外向內數，第六圈為圓圖卦名，第八圈為方圖卦名。
- **分金對照**：160 個紅點與 368 個格位（含 16 個雙倍寬格），保留細刻度與格界；資訊卡顯示目前格位是否有紅點及其起訖角度。
- **坐向雙讀值**：盤面中央上方顯示朝向，中央下方與畫面底部顯示坐山，度數顯示至小數點後兩位。
- **磁針與對照線**：中央磁針紅端指向磁北，固定細線貫穿盤層，便於對照卦象與刻度。
- **盤心縮放**：雙指以盤心縮放至六倍；放大後可拖曳查看局部，點兩下或按重設恢復原始大小。複雜盤支援全螢幕查看。
- **磁北／真北與方向鎖定**：可切換參考方向；真北未取得時會提示並改用磁北。

## 坐向約定

本版以手機頂端對應坐山，朝向為與坐山相差 180° 的對向。坐山／朝向是相對方向，內圈／外圈則分別指地盤正針／天盤縫針，兩者分開標示。天盤相對地盤錯開半個山位（7.5°）。

## 目前版本範圍

本次更新為 **1.0（建置版本 3）**。目前尚未加入完整時憲宿度、卦氣、卦運、挨星等盤層。砂水提示沿用簡易盤設定，不代表完整風水吉凶判斷。紅點按參考盤的標記與格界呈現，不另外將無紅點格推導為特定吉凶。

度數的小數位數代表顯示解析度，不代表測量精度。實際精度受手機感測器、磁性配件、附近金屬與環境干擾影響；細分格界應配合方向精度提示及實體羅盤覆核。

## 資料與隱私

App 不要求註冊帳號，沒有廣告、追蹤或第三方分析服務。方向及必要的定位資訊在裝置上供羅盤功能使用，不上傳至開發者伺服器；盤型偏好保留在本機。詳見[隱私權政策](https://jeihan101.github.io/mdcompass/privacy.html)。
